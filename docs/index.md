# Chronicity

Auto-generated API reference (from docstrings, via
[mkdocstrings](https://mkdocstrings.github.io/)) sitting alongside the hand-written project
docs — so the code's actual contract can be cross-checked against intent.

- **API reference** — `src/` modules and `tests/` (what each unit test asserts).
- **Schema / TODO / Questions** — the hand-written plan to check the code against.

Preview: `uv run mkdocs serve` · Build: `uv run mkdocs build`
