  Short answer: yes — but the word "DAG" is the catch, and it's the whole 
  problem. Your journeys are explicitly cyclic (med → fail → switch → fail →
  switch; P003, P006, P008 all loop). A DAG is acyclic by definition, and a
  Plotly Sankey requires acyclicity — feed it a loop and it either errors or
  renders nonsense. So the library choice hinges on how you want to handle the
  loops.

  Three approaches that actually fit:

  1. Transition-frequency table — pandas, zero new deps. Parse each pathway
  string into consecutive A -> B pairs, count them across all patients. This is
  the real engine for "iterate on the phases": it instantly shows which phase
  tokens are common vs. one-off (merge the rare ones into OTHER), and which
  transitions dominate. Not pretty, but it's the analytical backbone — and I can
  build it right now with nothing to install.

  2. Cyclic directed graph — networkx + graphviz (static) or pyvis 
  (interactive). A directed multigraph (not a DAG) models loops natively: nodes
  = phases, directed edges = transitions, edge thickness = frequency, self-loops
  and back-edges allowed. pyvis gives you a draggable HTML graph in the
  notebook (pure pip, no system binary); graphviz gives clean dot-layout images
  for the write-up (needs brew install graphviz). This is the faithful picture
  of the journeys including the circularity.

  3. Plotly Sankey — what you asked about. Doable and the prettiest, but only if
  you stage-index the nodes: relabel each step by its position, gp_visit@1 → 
  misdiagnosis@2 → …, so every occurrence is a unique node and the graph becomes
  acyclic. That reframes it as "what happens at journey-step N" — genuinely
  useful for seeing where journeys diverge over time — but it loses the "same
  phase recurring" identity, so a patient who hits insurance_denial twice shows
  as two different nodes.

  ▎ ★ Insight ─────────────────────────────────────
  ▎ This is the core modelling decision, not a library detail. A Sankey answers 
  ▎ "how does flow split as journeys progress through stages?" (time-ordered, 
  ▎ acyclic) — so cycles must be unrolled into stage-indexed nodes. A directed 
  ▎ graph answers "from any given phase, where do patients tend to go next?" (a 
  ▎ Markov-style transition view) — so cycles are first-class. For refining your
  ▎ phase vocabulary, the directed-graph/transition view is the better tool; 
  ▎ the Sankey is better later for a polished narrative of the aggregate 
  ▎ journey.
  ▎ ─────────────────────────────────────────────────

  ┌───────────────┬───────┬─────┬────────────────────────────────────────────┐
  │     Split     │ Cases │  %  │                    Role                    │
